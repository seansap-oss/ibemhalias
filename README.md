# IBEMH ALIAS - Modern UPSC Coaching Platform

![IBEMH ALIAS Preview](https://img.shields.io/badge/IBEMH-ALIAS-brightgreen) ![Tailwind CSS](https://img.shields.io/badge/Tailwind%20CSS-3.4-blue) ![Alpine.js](https://img.shields.io/badge/Alpine.js-3.x-purple)

**IBEMH ALIAS** is a modern, AI-powered UPSC coaching platform designed to help aspirants crack the Civil Services Examination through a unique blend of traditional mentorship and cutting-edge AI technology.

## ✨ Key Features

### 🎓 **Core Features**
- **AI-Powered Study Planner** - Personalized daily study schedules that adapt to your progress
- **Answer Writing Evaluator** - Instant AI feedback on your Mains answers with scoring and improvement tips
- **Current Affairs AI** - AI-summarized daily current affairs from 20+ sources
- **Mock Interview Simulator** - Practice with AI interviewer using voice interaction and DAF-based questions
- **Performance Analytics** - Track your progress with detailed dashboards and predictions
- **24/7 AI Support** - Chatbot assistance for any UPSC-related queries

### 🎨 **Design Features**
- **Dark/Light Mode** - Toggle between themes with system preference detection
- **Fully Responsive** - Mobile-first design with burger menu navigation
- **Interactive Components** - Smooth animations, hover effects, and transitions
- **Modern UI** - Gradient buttons, glass-morphism cards, and clean layouts
- **PWA Support** - Installable as a mobile app

### 📱 **Pages**
- **Home** - Hero section, features, courses, toppers gallery, testimonials
- **About** - Story, mission/vision, values, timeline
- **Courses** - Platinum, Gold, Silver batches, weekend courses, AI tools
- **Faculty** - Expert mentors, AI collaboration
- **Success Stories** - Topper profiles, video testimonials
- **AI Assistant** - AI features showcase, pricing, interactive demo
- **Blog** - Articles on strategy, current affairs, tips
- **Contact** - Multi-center locations, contact form, map

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **Tailwind CSS 3.4** - Utility-first CSS framework (CDN)
- **Alpine.js 3** - Minimal JavaScript framework for interactivity
- **Font Awesome 6** - Icons
- **Google Fonts** - Inter and Poppins typography

## 🚀 Getting Started

### Prerequisites
- Any modern browser (Chrome, Firefox, Safari, Edge)
- No build step required - runs directly from the browser

### Installation

```bash
# Clone the repository
git clone https://github.com/seansap-oss/ibemhalias.git
cd ibemhalias

# Open in browser
open index.html  # macOS
# or simply double-click index.html

# Or use a local server (recommended)
npx serve
```

For development with Tailwind CLI:
```bash
npm install
npm run dev
npm run build
```

## 📊 Design System

### Colors
- **Primary:** Amber → Gold gradient (`#f59e0b` → `#d97706`)
- **Secondary:** Teal → Blue gradient (`#0ea5e9` → `#2563eb`)
- **Dark Mode:** Deep charcoal (`#171717`) with amber accents

### Typography
- **Headings:** Poppins (display font)
- **Body:** Inter (sans-serif)

### Components
- Glass-morphism cards with blur effect
- Gradient buttons with hover animations
- Floating AI chatbot with quick actions
- Interactive progress bars and counters
- Testimonial carousels and topper profiles
